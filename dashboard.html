1. 대시보드 요약 (Overview)

이번 Phase 4는 기존 시스템에 잔존하던 18가지 리뷰 결함을 완전히 해소하고 견고한 기반(Foundation)을 다지는 데 집중했습니다.

Data Integrity

총 12개 문제 데이터셋 포맷 오류 100% 교정 (오류 0개).

Logic Defense

오답 노트 매핑 논리 결함 복구 및 풀이 상태(History) 동기화 완벽 처리.

Optimization

데드 코드(#cstsPage) 100여 줄 제거를 통한 렌더링 성능 최적화.

2. 기획 (Product Requirements)

🎯 프로덕트 비전

"어디서나 끊김 없이 빠르고 직관적인 자격증 기출문제 학습 경험 제공"

  • 타겟 유저: ISTQB FL 및 CSTS 자격증을 준비하는 수험생
  • 핵심 가치: 네트워크 없는 환경(Offline)에서도 동작하는 PWA 앱, 태블릿/모바일/PC 어디서나 반응하는 UI
  • 주요 차별점: 로딩 없는 즉각적인 문제 전환, 로컬 영속성(IndexedDB)을 활용한 완벽한 상태 복원력

3. 기능 명세서 (Functional Specification)

기능 ID 기능명 상세 설명 비고
F01 모드별 문제 풀이 연습(즉각 피드백), 시험(완료 후 채점), 랜덤(무작위 40제), 오답(틀린 문제만) 모드 제공. 핵심 비즈니스 로직
F02 오프라인 PWA 구동 Service Worker를 활용해 앱 에셋(HTML/CSS/JS/JSON)을 캐싱하여 오프라인에서 실행 가능. PWA Manifest
F03 영속성 상태 복원 사용자가 앱을 종료해도 IndexedDB와 LocalStorage를 통해 진행 중인 문제, 답안, 시간 보존. Auto-save
F04 타이머 기능 모드 진행 상황에 따른 백그라운드 시간 누적 및 일시정지 대응 로직. 초 단위 계산
F05 데이터 내보내기/가져오기 로컬 스토리지의 학습 상태(히스토리, 답안)를 JSON 파일로 백업하고 복원하는 기능. 기기 전환 시 유용
F06 시각적 설정 (UI) 글자 크기 조절(작게/기본/크게), 이미지 줌 인/아웃, 다크모드 대응. 접근성(a11y)

App Shell 아키텍처를 기반으로 좌측 컨트롤 패널(사이드바)과 우측 풀이 영역(워크스페이스)을 나눈 태블릿 뷰어 레이아웃입니다.

6. ERD (Entity Relationship Diagram)

오프라인 지향 앱이므로 별도 백엔드 DB 대신 JSON Static Data와 브라우저 IndexedDB (State)의 관계를 보여줍니다.

erDiagram APP_STATE ||--o{ ANSWER_RECORD : contains APP_STATE ||--o{ EXAM_HISTORY : stores APP_STATE ||--o{ REVIEW_IDS : tracks QUESTION_SET ||--|{ QUESTION : owns APP_STATE { string setId "현재 선택된 문제 세트 ID" string mode "exam, practice, random, review" int index "현재 문제 인덱스" float elapsedSeconds "진행 시간" } ANSWER_RECORD { string key "PK: setId-mode-questionId" array selectedChoices "사용자가 고른 보기 배열" } EXAM_HISTORY { string id "PK: Timestamp" string mode "시험 모드 정보" string setId "세트 정보" object answers "당시 제출한 답안 내역" } QUESTION { string id "고유 문제 ID" int number "문항 번호" string type "multiple_choice 등" string stem "문제 지문 HTML" array options "선택지 배열" array answer "정답 키 배열" string explanation "해설" }
