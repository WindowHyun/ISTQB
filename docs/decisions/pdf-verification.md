# PDF 대조(`verify-pdf-data.py`)의 규칙 상세

`docs/harness/data.md`가 규칙 한 줄로 가리키는 상세다. 새 허용 목록 항목을 넣거나 대조 규칙을 바꿀 때 읽는다. 실행 출력이 정본이고, 조각 수를 손으로 재현하려 하지 않는다.

## 비교가 지우는 것과 그래서 따로 보는 것

- [1]~[4]는 비교 전에 공백과 문장부호를 지운다. 그래서 **해설**(항목 라벨 `A.`·연결 번호 `(4)`·분수 `3/5`가 빠진 것)과 **줄바꿈 자리 공백**("준 비 중"·"올바른것은")은 [5]·[6]이 따로 본다. **코드 줄과 구조화된 표**는 [1]이 따로 본다 — `norm()`은 `+ - =`를 지워 "Z = X + Y"와 "Z = X - Y"를 구분하지 못하므로, 코드 블록은 공백만 지운 글이 **그 문항의** PDF 줄을 이은 글(코드 옆에 표가 나란히 놓인 쪽은 같은 열끼리 이은 글)에 연속으로 들어 있는지, 표는 **그 문항이 놓인 자리의** PDF 표 격자(`find_tables`)와 칸 단위로 맞춘다(병합 칸은 행을 접어 행 단위로 비교). 일치 구간은 PDF 줄의 처음과 끝에 맞아야 하고 구간 바로 앞뒤의 PDF 줄은 지문의 다른 글에 있어야 하므로, "Z = X + Y"가 "Z = X"로 잘리거나 프로그램의 앞뒤 문장이 빠지거나 다른 문항의 표를 가져다 붙이면 걸린다. 한 문항의 표 여러 개는 서로 다른 PDF 격자를 하나씩 쓴다(표를 다른 표로 바꿔 놓으면 걸린다). PDF에 표 격자가 있는데 JSON에 표 블록이 없으면(블록을 지웠거나 그림으로 바뀌면) 걸린다 — 표가 그림으로 실린 문항은 `TABLE_AS_FIGURE`에 표 개수와 그 그림 경로를 눈으로 확인해 적고(그림이 지워지거나 바뀌어도 걸린다), "정답" 상자와 칸 글자가 JSON 본문·코드에 그대로 있는 표는 적지 않아도 된다. 지문의 `formula` 블록도 같은 비교를 받고, 수식이 PDF에서 글이 아니라 그림(수식 개체)인 문항은 `FORMULA_AS_IMAGE`에 눈으로 확인한 수식 문자열을 적어 고정한다(그 문항 지문의 수식 블록이 등록된 것과 정확히 같아야 하므로 블록을 지워도 걸린다). 수식이 든 해설은 글자 비교에 더해 연산자(`+ - * / = < > ≤ ≥ × ÷ %`)와 순서를 따로 맞춘다. 병합 칸 표(이어지는 행·가로 병합)는 칸 경계까지 맞추고, 병합 머리글 위치만 다른 표는 `TABLE_HEADER`에 머리글 한 줄을 적는다. 병합 칸 표는 머리글 앞 칸·(위층 머리글+아래층 머리글)·첫 열("조건"/"행위" 묶음)·본문 행 전부를 순서대로, `< > =` 같은 연산자까지 맞춘다. PDF의 두 층 머리글을 JSON이 한 줄로 편 표는 `TABLE_HEADER`에 머리글 한 줄만 눈으로 확인해 적는다(표 전체를 면제하지 않는다). 테두리 없는 표라 격자가 안 잡히면 `ALLOW`의 `("table", …)`·`("code", …)`에 눈으로 확인한 사유와 함께 적는다. [5]는 ISTQB 해설을 정답과 해설 PDF의 행과 글자 단위로 맞추고, CSTS 2018 "정답 및 해설"은 "N. 정답" 줄로 문항을 나눠 **그 문항의** PDF 해설 글과 JSON 해설 글이 양방향으로 같은지(다른 문항 해설이 덧붙어도 걸린다), 해설 표가 PDF 표 격자와 칸 단위로 같은지 본다. [6]은 지문·보기·해설(CSTS 2018 해설 포함)에서 PDF 줄바꿈이 낱말 중간인지 띄어쓰기인지를 줄 끝 공백 글리프로 판정해 JSON의 같은 자리와 맞춘다(2018 PDF 일부 구간은 공백을 `\x01` 글리프로 싣는다). **글리프가 없는 줄바꿈은 낱말 중간 꺾임으로 읽기 때문에 실제 띄어쓰기를 놓칠 수 있다** — 그런 자리를 눈으로 확인해 JSON이 맞으면 `ALLOW_WRAP`에 앞뒤 글과 사유를 적는다(띄어 쓴 글이 문항에 계속 있어야 하므로 다시 붙이면 걸린다). 수식어 뒤 의존명사("유한 개의")처럼 붙이면 틀리는 곳이 대표적이다. 원본 PDF의 오탈자를 JSON이 바로잡아 둔 해설은 `EXPL_TYPO`에 오탈자 앞뒤 글만 적는다(문항 전체를 면제하지 않으므로 같은 해설의 다른 글자가 틀리면 여전히 실패한다).
