# 업데이트 내역 (2026-06-08)

## 1. CSTS 데이터 포맷팅 및 오류 수정
- **전수 검증 스크립트 도입**: Playwright 기반 자동화 스크립트(`audit-csts.js`)를 작성하여 CSTS 약 500문항의 화면 렌더링 상태를 전수 조사하고 레이아웃 깨짐을 방지.
- **CSTS 2402FL 4번 문제**: `1.1 기능 1`, `1.2 기능 2` 등 여러 항목이 한 줄로 뭉쳐서 출력되던 현상을 리스트 형태로 분리하여 가독성 개선.
- **CSTS 2402FL 24번 문제**: `A.` 부터 `J.` 까지의 테스트 기법 목록이 문제 본문에 섞여 나오던 문제를 수정하여 `<보기>` 박스 안으로 정상적으로 들어가도록 조치.
- **CSTS 2402FL 26번 문제**: 여러 개의 `테스트 케이스`가 한 줄로 길게 이어져 출력되던 문제를 각각 개행 처리하여 식별하기 쉽게 개선.

## 2. UI / UX 개선 (설정 패널)
- **설정 메뉴 Z-index 충돌 및 위치 오류 해결**: 설정 버튼 클릭 시 전체 화면이 딤(Dim) 처리되면서 설정 패널이 좌측 상단으로 찌그러지던 레이아웃 붕괴 현상 수정.
- **모달창 개편**: 설정 패널을 사이드바 종속에서 벗어나 화면 중앙에 뜨는 독립적인 팝업 모달(Modal)창으로 디자인 개편. 이를 통해 백드롭 오버레이와의 호환성을 확보하고 조작성을 크게 향상시킴.

## 3. ISTQB 샘플 문제 세트 인코딩 오류 복구
- **타이틀 깨짐 현상 수정**: 기존 데이터 변환 과정에서 한글이 깨져 `ISTQB FL v4.0 ???? A` 와 같이 표기되던 세트 제목들을 `ISTQB FL v4.0 샘플문제 A` 형식으로 일괄 복원.
- 대상 파일: `public/data/index.json` 및 `istqb/sample-a~extra.json` 전체 파일. JSON 파싱 에러(Invalid JSON)가 발생하지 않도록 정규식 대신 안전한 문자열 치환 로직을 적용함.
