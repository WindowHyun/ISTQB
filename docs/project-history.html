2. 어떤 기획이 수정되었나

단순 문제풀이 앱 → 학습 사이클(응시 → 분석 → 보완 → 재측정)을 가진 CBT로 확장.

Phase 0 문항 분류 체계 (07-09)

626문항 전체에 대단원(chapter) 태깅 — ISTQB 6챕터 / CSTS 6도메인(taxonomy.json). 키워드 추론 + 수동 오버라이드 전수 분류, 공식 정답 PDF의 학습목표(LO)로 대조해 6건 교정. 약점 분석의 데이터 기반.

Phase 1 시험 시작 게이트 + 응시 중 잠금 (07-09)

시험 모드는 "시험 시작"을 눌러야 응시 개시(타이머 0부터). 응시 중(채점 전)에는 세트·모드 변경 잠금 + 🔒 안내. 새로고침해도 답안 존재 = 응시 개시로 보고 잠금 유지(리로드 우회 방지).

Phase 2 학습 누적 — 회차 비교·성장 이력 (07-10)

채점 결과에 직전 회차 대비 ▲/▼ %p(첫 응시 안내), 학습 통계에 세트별 회차 타임라인(1회차→N회차 정답률·성장폭). 표본 왜곡 방지를 위해 델타는 같은 모드끼리만 비교.

Phase 3 챕터 약점 분석·집중 연습·오답 누적 (07-09~10)

챕터별 정답률(약점 강조·자격증별 컷 기준 ISTQB 65%/CSTS 75%)·가중 평균. 챕터 집중 연습 진입(세트에 챕터가 없으면 보유 세트로 자동 전환). 오답노트는 전 회차 합집합 누적.

Phase 4 영속화 강화 (07-11)

백업 스키마 버전(v1, 미래 버전 거부)·가져오기 원자성(IDB 커밋 후 localStorage, 부분 성공 안내)·저장공간 90% 경고. 손상 백업 방어(클램프·프로토타입 오염 키 차단).

정책 결정·개정 주요 기획 판단

  • 랜덤 이어풀기 없음(F4) — 진입·재접속마다 새 추첨(같은 세션 내 재풀이는 같은 추첨). 07-12에 재추첨 안내 토스트·'새 문제 뽑기' 명시 버튼으로 보완
  • 채점한 시험 재접속 정책(#1 → S4 개정) — "재접속하면 다시 풀 수 있게 초기화"에서 "채점 완료 회차는 가드 모달(지난 결과 보기/새 회차 시작)"로 개정 — 동일 답안 재채점의 회차 중복 적립 차단
  • 진입 시 항상 제품 게이트(#5) — 저장된 진행은 제품 선택 후 복원
  • 연습은 통계 무기록 — 정답률 갱신은 시험·랜덤·미니 시험 채점으로(배너에 명시)

S1~S6 흐름·기획 리뷰 반영 (07-12, 최종 배치)

AS-IS 잠금 중 탈출구가 '설정→처음 화면으로' 비공식 우회로뿐
TO-BE(S2) 공식 '응시 포기' 버튼+확인 모달(기록 없음), 처음 화면 이동도 확인 경유
AS-IS 채점 후 새로고침 → 미채점처럼 보여 중복 회차 적립 가능
TO-BE(S4) '채점 완료된 회차' 가드 — 지난 결과 보기 / 새 회차 시작만 제공
AS-IS 약점 연습해도 통계 갱신 안 됨(재측정 수단 없음)
TO-BE(S3) 챕터 미니 시험(10문항 추첨·챕터 통계 반영) — 학습 루프 완성
AS-IS 랜덤 새로고침 시 무통보 초기화 / 새 추첨 방법이 숨은 규칙
TO-BE(S1·S5) 재추첨 정책 토스트 안내 + '🔀 새 문제 뽑기' 버튼
AS-IS 한 번 틀린 문항은 오답노트에 영구히 '복습 대상'처럼 잔존
TO-BE(S6) 최근 시험 2회 연속 정답이면 '✓ 극복' 배지+흐림(목록엔 유지)
