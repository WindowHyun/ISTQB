## 버그 개요

앱 로직(`script.js`)과 스타일(`style.css`)이 **루트와 `www/`에 중복 존재**하며 내용이 서로 다릅니다. 데이터 분기(#52)와 같은 문제이나, 코드는 **양방향으로 분기**되어 있어(각자 다른 변경 존재) 단순 통일이 위험합니다.

- 등급: **High (유지보수 / 정합성)**

- 루트 vs www `script.js` diff: 약 290줄 상이.
- 차이의 상당 부분은 **`www/script.js`에만 있는 CSTS 미리보기 코드**(`cstsPage`, `renderCstsPage` 등 — 이슈 #43의 dead code). 즉 루트는 일부 정리됐고 www엔 남아있는 등 **양쪽이 서로 다른 방향으로 변경**됨.

## 영향
- 로직 버그(#35·#36·#40·#45 등)를 한쪽만 고치면 다른 진입점(웹 또는 APK)에는 반영되지 않음.
- 어느 쪽이 정본인지 불명확하여, 수정 시 양쪽에 각각 적용하거나 먼저 통일이 필요.

## 해결 방향(논의)

1. 로직/스타일의 단일 정본 확립 후 빌드에서 배포 경로로 복사(데이터 #52와 동일 전략).
2. 통일 전, 두 파일의 diff를 검토하여 어느 변경이 최신/정답인지 결정(dead code(#43) 제거와 함께 진행 권장).
3. 통일 전까지 버그 수정은 **루트·www 양쪽에 동일 적용**.
