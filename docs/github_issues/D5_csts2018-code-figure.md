## 버그 개요

CSTS 2018 일반등급 예제에서 **코드 블록이 엉뚱한 문항에 배치**되고, 그림 자산이 누락된 문제가 있습니다.

- 등급: **Critical (데이터 정합성)**
- 대상: `www/data/csts/csts-2018-general.json`

---

## 현재 상태

### 1. 코드 블록 위치 뒤바뀜 (12 ↔ 15)
- PDF: **12번** 지문에 코드 블록 포함
  ```
  IF ((X > 10) OR (Y == 2)) Z = X + Y
  IF ((X < Z) AND (Y > 15)) Z = X
  IF (X <= Z) PRINT(Z)
  ```
  **15번**은 코드가 아니라 "자료 흐름도" 그림 문항.
- JSON: 위 코드 블록이 **15번** stem에 들어가 있고, **12번**에는 코드/그림이 전혀 없어 문제 성립 불가.

### 2. 15번 자료 흐름도 그림 자산 누락
- PDF 15번은 자료 흐름도 그림 문항이나, JSON에 그림 노드도 없고 자산 파일(png)도 부재.

### 3. 11번 figure 필드 불일치
- PDF 11번은 제어 흐름도 그림 문항. 자산 `www/csts-figures/2018-SAMPLE-11.png`는 실재.
- JSON: stem에 image 노드는 있으나 최상위 `figure: null` (Q9·Q20은 figure가 채워져 있어 형식 불일치).

---

## 기대 동작

1. 12번 코드 블록을 12번 stem으로 되돌린다.
2. 15번에 자료 흐름도 그림을 배치한다(자산 확보 필요).
3. 11번 figure 필드를 Q9/Q20과 동일 규약으로 통일한다.
