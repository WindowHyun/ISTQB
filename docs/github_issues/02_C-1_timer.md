## 버그 개요

채점이 끝난 뒤에도 경과 시간 타이머가 계속 증가합니다.

- 등급: **Critical**
- 대상 파일: `www/script.js`

---

## 재현 절차

1. 시험 모드로 문제를 푼다.
2. 채점 버튼을 눌러 채점을 완료한다.
3. 화면에 표시된 경과 시간을 관찰한다.

## 현재 동작 (버그)

- `setInterval(updateTimer, 1000)`이 앱 전역에 한 번만 등록되고 `clearInterval`로 멈추는 처리가 없음 (`script.js` 약 line 3668).
- `updateTimer()`가 채점 완료 여부와 무관하게 매초 `elapsedSeconds`를 누적함.
- 따라서 채점 후에도 타이머가 계속 올라감.

## 기대 동작

1. 채점이 완료되면 타이머가 멈추고 최종 소요 시간이 고정 표시된다.
2. 새 세트를 시작하면 타이머가 다시 동작한다.
