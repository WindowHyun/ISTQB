## 버그 개요

원본 PDF와 사이트 JSON(`www/data/`)을 대조한 결과, **여러 문항의 지문(stem)이 원본과 다른 문제의 내용으로 잘못 채워져** 있습니다. 보기(options)·정답(answer)·해설(explanation)은 올바른 문제의 것인데 **지문만 다른 문제로 바뀐** 데이터 오염입니다. 사용자가 보는 문제 질문 자체가 원본과 달라 정상적인 학습이 불가능합니다.

- 등급: **Critical (데이터 정합성)**
- 검증 방법: 원본 PDF 추출 텍스트 ↔ `www/data/istqb/*.json` 1:1 대조

2. ⅰ~ⅴ 목록, 표(테스트 차터·플래닝 포커·결정 테이블 등)와 `<보기>` 본문도 원본대로 복원한다.
3. 문제 8(D)의 불필요한 `choices[]` 오염 필드를 제거한다.
