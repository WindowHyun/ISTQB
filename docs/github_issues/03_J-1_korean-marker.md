## 버그 개요

문제 본문(stem)에 쓰인 한글 보기 마커(`가.`, `나.`, `다.`, `라.`)가 구조화된 목록(structured list)으로 인식되지 않아, 보기가 한 줄로 뭉쳐 가독성이 크게 떨어집니다.

- 등급: **High**
- 대상 파일: `www/script.js`

---

## 재현 절차

1. 한글 마커(`가.`/`나.`/`다.`/`라.`)로 보기가 구성된 문항을 연다.
2. 보기가 줄바꿈/들여쓰기 없이 일반 텍스트로 렌더링되는지 확인한다.

## 현재 동작 (버그)

- `parseStructuredItem()`의 마커 인식 정규식(`script.js` 약 line 2122~2126)에 `숫자.`, `(숫자)`, `A.`, `a)`, 로마자, 불릿은 있으나 **한글 마커(`가.`/`나.`/`다.`/`라.`)가 누락**됨.
- `fixNewlines`에는 `가.나.다.라.` 줄바꿈 처리가 있으나(약 line 99~100), `parseStructuredItem`에서 목록 아이템으로 인식하지 못해 일반 텍스트로 렌더링됨.
- 다수 문항 stem에 이 마커가 사용되어 가독성이 파괴됨.

## 기대 동작

1. 한글 마커로 시작하는 보기가 구조화된 목록 항목으로 렌더링된다.
2. 기존 마커(숫자/영문/로마자/불릿)와 동일한 들여쓰기·줄바꿈을 가진다.
