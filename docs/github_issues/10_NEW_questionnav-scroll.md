## 버그 개요

사이드바의 문제 번호 네비게이션(questionNav)에서, 현재 문제 버튼이 뷰포트 밖에 있어도 자동으로 스크롤되지 않아 현재 위치를 찾기 어렵습니다.

- 등급: **Medium**
- 대상 파일: `www/script.js`
- 비고: QA 리포트의 [D-1]은 워크스페이스 본문 스크롤(`scrollQuestionIntoView`)을 가리키며 이미 구현되어 있음. 본 이슈는 그와 **구분되는 별도의 네비 패널 스크롤** 문제임.

---

## 재현 절차

1. 문항 수가 많은 세트를 연다.
2. 네비 패널에서 보이지 않는 뒤쪽 번호로 이동한다.
3. 현재 문제 버튼이 네비 패널 내에서 자동으로 보이는 위치로 스크롤되는지 확인한다.

## 현재 동작 (버그)

- 본문은 `scrollQuestionIntoView("auto")`(`script.js` 약 line 2855)로 워크스페이스 상단 스크롤이 동작함.
- 그러나 questionNav 패널 내부에서 **현재 문제 버튼을 뷰 안으로 스크롤하는 코드가 없음**.

## 기대 동작

1. 문제 이동 시 네비 패널에서 현재 문제 버튼이 자동으로 보이는 위치로 스크롤된다.
2. 패널 가독성과 위치 파악이 개선된다.
