## 버그 개요

원본 PDF ↔ 사이트 JSON 대조 결과, 여러 CSTS 문항에서 **지문(stem) 또는 보기(`<보기>`)의 본문이 중간에 잘려 누락**되어 있습니다. 정답·해설은 있으나, 문제의 핵심 문장(빈칸을 포함한 문장, 판단 대상 문장, 보기 항목)이 사라져 **그대로는 문제를 풀 수 없습니다.**

- 등급: **Critical (데이터 정합성)**

---

## 영향받는 문항

| 세트 | 문제 | 누락 내용 |
|------|------|-----------|
| CSTS-2402FL | 64 | 빈칸 문장 전체 누락. PDF: "…확인할 필요가 있다. 이를 위하여 초기에 결함을 검출한 테스트 케이스를 이용하여 테스팅을 다시 수행하는데, 이를 ( ) 이라고 부른다." / JSON: "…확인 할 필요가 있"에서 끊김 |
| CSTS-2403FL | 6 | `<보기>` (가)·(라) 항목 통째로 누락, (나)·(다) 앞부분 잘림(환경·수행주체 설명 소실) |
| CSTS-2403FL | 65 | ISO 26262 설명 및 밑줄 친 활동 문장("이러한 표준 준수 여부를 독립적으로 평가하고 교정활동을 요구하는 보고서를 산출하게 한다.") 누락. JSON: "…큰 위험을 초래할 수 있"에서 끊김 |
| CSTS-2404FL | 51 | 둘째 문장 + (○/X) 표기 누락. PDF: "…중요하다. 이는 테스트 환경과 실제 환경의 차이가 크면 클수록 … 커지기 때문이다. ( ○ / X )" / JSON: "…수행하는 것이 중요하"에서 끊김 |
| CSTS-EXAMPLE | 51 | 위 2404 51번과 동일 패턴(둘째 문장·○/X 누락) |
| CSTS-EXAMPLE | 64 | 위 2402 64번과 동일 패턴(빈칸 문장 전체 누락) |

### 정답 데이터 누락 (함께 처리)

| 세트 | 문제 | 내용 |
|------|------|------|
| CSTS-2403FL | 70 | `answer`/`answerText`가 빈 문자열. PDF 정답: "결함 분석, 결함 판단, 테스트 결과 분석, 결과 분석, 테스트 실행 결과 분석" |

> 경미(참고): CSTS-2404 63·66번은 핵심 문장 뒤 **부연 설명부**가 절단됨. 정답 도출에는 영향 없으나 함께 복원 권장.

## 기대 동작

1. 각 문항의 잘린 지문/보기 본문을 원본 PDF 전문으로 복원한다.
2. CSTS-2403 70번의 정답 데이터를 채운다.

## 완료 조건

* [ ] CSTS-2402 64 / 2403 6·65 / 2404 51 / example 51·64 지문 복원
* [ ] CSTS-2403 70 정답 입력
* [ ] (권장) CSTS-2404 63·66 부연부 복원
* [ ] 원본 PDF와 재대조
