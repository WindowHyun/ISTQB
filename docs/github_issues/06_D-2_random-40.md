## 버그 개요

랜덤 모드가 "40문항"으로 하드코딩되어 있어, 가용 문제 수가 40개 미만일 경우 무한 재셔플 등 비정상 동작 위험이 있습니다.

- 등급: **High**
- 대상 파일: `www/script.js`

---

## 재현 절차

1. 가용 문제 수가 40개 미만인 상황을 가정한다.
2. 랜덤 모드를 시작한다.

## 현재 동작 (버그)

- `generateRandomRefs()`에 `.slice(0, 40)` 하드코딩 (`script.js` 약 line 493~499).
- `randomQuestions()`에 `state.randomRefs.length !== 40` 조건 (약 line 503).
- 세트 메타 텍스트에 `"전체 랜덤 40문항"` 문자열 하드코딩 (약 line 2738).
- 데이터가 40개 미만이면 길이 조건을 만족하지 못해 재셔플이 반복될 위험.

## 기대 동작

1. 문항 수가 가용 문제 수에 맞춰 동적으로 결정된다 (`min(40, total)`).
2. 메타 텍스트가 실제 출제 문항 수를 반영한다.
3. 가용 문제가 40개 미만이어도 정상 출제된다.
