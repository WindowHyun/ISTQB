## 버그 개요

ISTQB 샘플문제 C의 31번은 원본 PDF에서 **그래프(이미지)** 로 데이터를 제시하는 문항입니다. 그런데 JSON에서는 그래프 없이(`figure: null`) stem 안에 데이터를 텍스트로 옮겼는데, **옮긴 수치가 정답 해설이 사용하는 값과 맞지 않습니다.** 정답 신뢰성에 영향을 줄 수 있어 검토가 필요합니다.

- 등급: **Critical (데이터 정합성 / 정답 신뢰성)**
- 대상: `www/data/istqb/sample-c.json` 31번

---

## 현재 상태

- PDF: "그래프는 처음 4번 반복주기의 예상 작업량과 실제 작업량을 보여주고 있다" + 그래프 이미지
- JSON: `figure: null`. 그래프 대신 stem에 텍스트 데이터 삽입 (예: "반복주기 1: 예상 50, 실제 45" … "반복주기 4: 예상 54, 실제 45")
- **불일치**: JSON에 옮긴 반복주기 3·4의 실제값이, 정답 해설이 사용하는 값(A(3)=8, A(4)=6)과 정합하지 않음

## 기대 동작

1. 원본 그래프의 정확한 수치를 확인하여 stem 텍스트(또는 그래프 이미지)를 원본과 일치시킨다.
2. 옮긴 데이터와 정답 해설의 계산값이 일관되도록 한다.
3. 가능하면 그래프 이미지를 `figure`로 제공한다(표시 방식은 별도 figure 이슈와 연계).
